# Claim → source → test matrix

Factual mapping of externally relevant runtime/security claims to their authoritative code/config sources and the parity tests that guard against drift. Claims are verified against constants, route registration, and signatures (not marketing copy).

| Claim | Code/config source | Test |
|---|---|---|
| WebSocket gateway endpoint is `GET(ws) /gateway` (top-level, **not** under `/api/v1`) | `src/api/websocket/gateway.py` (`@router.websocket("/gateway")`), `src/api/app.py` mounts `gateway_router` without `config.api_prefix` | `src/tests/security/test_claim_parity.py::test_gateway_websocket_path_is_root_gateway_not_api_v1` |
| Readiness probe `GET /api/v1/ready` (liveness, minimal) | `src/api/routes/health.py` (`/ready`), router mounted at `config.api_prefix` in `src/api/app.py` (default `/api/v1`, `src/api/config.py`) | `src/tests/security/test_claim_parity.py::test_health_router_defines_health_and_ready_under_api_prefix_mount` |
| Health `GET /api/v1/health` (detailed) | `src/api/routes/health.py` (`/health`), mounted at `config.api_prefix` | `src/tests/security/test_claim_parity.py::test_health_router_defines_health_and_ready_under_api_prefix_mount` |
| Root `GET /health` proxies to the canonical `/api/v1/health` handler | `src/api/app.py` root `/health` delegates to `src.api.routes.health.health_check` | `src/tests/security/test_claim_parity.py::test_root_health_path_proxies_to_api_health_handler` |
| PKCE uses `S256` only (no `plain`); challenge required | `src/api/routes/auth/oauth.py` (`code_challenge_method` rejects non-`S256`, challenge required, sets `S256`), `src/core/auth/oauth/pkce.py` (`code_challenge_method="S256"`, SHA-256) | `src/tests/security/test_claim_parity.py::test_oauth_state_cookie_name_and_pkce_constants`, `test_oauth_login_enforces_s256_and_requires_challenge` |
| OAuth state cookie name is `plexichat_oauth_state`, `HttpOnly`/`SameSite=Lax`, scoped to `{api_prefix}/auth/oauth` | `src/api/routes/auth/oauth.py` (`OAUTH_STATE_COOKIE`, `_oauth_cookie_params`) | `src/tests/security/test_claim_parity.py::test_oauth_state_cookie_name_and_pkce_constants` |
| OAuth login must **not** accept `code_verifier` (server never mints/accepts verifier at login; PKCE secrecy, task 6) | `src/api/routes/auth/oauth.py::oauth_login_init` signature — only `code_challenge`/`code_challenge_method` | `src/tests/security/test_claim_parity.py::test_oauth_login_does_not_accept_code_verifier_param` |
| Channel ratchet opcode `50` / `RATCHET_UPDATE` | `src/api/websocket/opcodes.py` (`GatewayOpcode.RATCHET_UPDATE = 50`) | `src/tests/security/test_claim_parity.py::test_ratchet_opcode_and_event_name_constants` |
| Ratchet rotation defaults: `1000` messages or `86400` seconds per interval (licensed feature; wire `ENC:3:`) | `src/utils/encryption/channel_ratchet/manager.py` (`DEFAULT_MAX_MESSAGES_PER_INTERVAL`, `DEFAULT_MAX_INTERVAL_AGE_SECONDS`, config keys `ratchet_max_messages`/`ratchet_max_age_seconds`) | `src/tests/security/test_claim_parity.py::test_ratchet_rotation_defaults_1000_msgs_or_86400s` |
| DSAR endpoints under `/api/v1/users/@me/data-export*` (create/list/status/cancel/download) | `src/api/routes/users/composer.py` (`/@me/data-export`, `/{request_id}`, `/{request_id}/download`), users router mounted at `/users` in `src/api/routes/__init__.py`, api at `/api/v1` | `src/tests/security/test_claim_parity.py::test_dsar_data_export_routes_and_rate_limit` |
| DSAR export-create limited to `1` request per `24h` (`86400s`) per user | `src/api/routes/users/dsar.py` (`@custom_rate_limit(config=RateLimitConfig(requests=1, window_seconds=86400))` on `request_data_export`) | `src/tests/security/test_claim_parity.py::test_dsar_data_export_routes_and_rate_limit` |
| Rate-limit shipped defaults (overridable; fallbacks aligned with `src/config_defaults.py`): global `25000/60s` + `burst 5000` (token bucket); user `10000/60s` + `burst 2500`, hourly `300000`, daily `5000000`; IP `5000/60s` + `burst 1500`, hourly `150000`, daily `1000000` | `src/core/ratelimit/config.py` (`_build_global_limit/_build_user_limit/_build_ip_limit`, `utils.config` `rate_limiting.*`), `src/config_defaults.py` (`rate_limiting`) | `src/tests/security/test_claim_parity.py::test_ratelimit_global_user_ip_defaults` |

Notes:
- “Licensed” behavior (e.g., ratchet) is a product gate layered above these runtime defaults; the defaults/opcode/cookie/path claims above remain verifiable in code regardless of license state.
- When a claim intentionally changes, update the source of truth **and** this matrix/test in the same change.
