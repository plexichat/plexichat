# Build a custom client

Build a custom Plexichat client from scratch, including authentication, WebSocket gateway integration, state management, encryption, and theming.

## Overview

A Plexichat client needs:

- REST API integration for authentication and data.
- A WebSocket gateway connection for real-time events at `/gateway` (`src/api/websocket/gateway.py:261`).
- Local state management and caching.
- Message decryption.
- UI rendering for messages, servers, and channels.

**Base URLs**

| Environment | REST | Gateway |
|---|---|---|
| Production | `https://api.plexichat.com/api/v1` | `wss://api.plexichat.com/gateway` |
| Development | `http://localhost:8000/api/v1` | `ws://localhost:8000/gateway` |

The API prefix defaults to `/api/v1` (`src/config_defaults.py:131`). All REST paths in this guide include that prefix.

## Authenticate

### Register a new account

```http
POST /api/v1/auth/register
Content-Type: application/json

{
  "username": "johndoe",
  "email": "john@example.com",
  "password": "SecurePass123!"
}
```

Response `201 Created`:

```json
{
  "status": "success",
  "token": "session_token_here",
  "user": {
    "id": "123456789012345678",
    "username": "johndoe",
    "email": "john@example.com"
  }
}
```

### Log in

```http
POST /api/v1/auth/login
Content-Type: application/json

{
  "username": "johndoe",
  "password": "SecurePass123!"
}
```

The request body uses `username` for both usernames and email addresses. A request with an `email` key fails validation.

Response `200 OK`:

```json
{
  "status": "success",
  "token": "session_token_here",
  "user": {
    "id": "123456789012345678",
    "username": "johndoe",
    "email": "john@example.com"
  }
}
```

### Handle two-factor authentication

If 2FA is enabled, login still returns `200 OK`, but with `two_factor_required` instead of a session token:

```json
{
  "status": "two_factor_required",
  "token": null,
  "user": null,
  "challenge_token": "challenge_token_here",
  "methods": ["totp", "backup_code"],
  "expires_in": 300
}
```

Submit the code with the challenge token:

```http
POST /api/v1/auth/2fa
Content-Type: application/json

{
  "challenge_token": "challenge_token_here",
  "code": "123456"
}
```

On success, the endpoint returns a standard `LoginResponse` with `token` and `user`. Invalid or expired codes return `401` with `{"error":{"code":401,"message":"..."}}`.

### Sign in with OAuth (PKCE S256)

Plexichat supports OAuth with Google, GitHub, Microsoft, and GitLab. PKCE is enabled by default and uses `S256` (`src/api/routes/auth/oauth.py:195`).

**Step 1: Initiate login**

```http
GET /api/v1/auth/oauth/{provider}/login?redirect_uri=https://app.example.com/callback&code_challenge=E9Melhoa2OwvFrEMTJguCHaoeK1t8URWbuGJSstw-cM&code_challenge_method=S256
```

| Parameter | Required | Description |
|---|---|---|
| `provider` | Yes | `google`, `github`, `microsoft`, or `gitlab` |
| `redirect_uri` | Yes | Must exactly match an entry in the provider's `allowed_redirect_uris` allow-list. Only a trailing slash is normalized; prefix or substring matches are rejected with `400` (`src/api/routes/auth/oauth.py:68`) |
| `code_challenge` | Yes when PKCE is enabled | S256 challenge generated by the browser (43–128 characters: `A-Z a-z 0-9 - . _ ~`). The server never mints a verifier for you and rejects `plain` (`src/api/routes/auth/oauth.py:202`) |
| `code_challenge_method` | No | Must be `S256` if provided |

Response `200 OK`:

```json
{
  "url": "https://accounts.google.com/o/oauth2/v2/auth?client_id=...&state=...",
  "auth_url": "https://accounts.google.com/o/oauth2/v2/auth?client_id=...&state=...",
  "state": "random_state_string"
}
```

The server also sets a short-lived `HttpOnly` cookie named `plexichat_oauth_state` scoped to `${api_prefix}/auth/oauth` (`src/api/routes/auth/oauth.py:91`). You must return the same `state` value in the callback, and the cookie must match it. A mismatch fails with `400` and blocks login CSRF.

**Step 2: Handle the callback**

```http
POST /api/v1/auth/oauth/{provider}/callback
Content-Type: application/json

{
  "code": "authorization_code_from_provider",
  "state": "random_state_string",
  "redirect_uri": "https://app.example.com/callback",
  "code_verifier": "dBjftJeZ4CVP-mB92K27uhbUJU1p1r_wW1gFWFOEjXk"
}
```

| Field | Required | Description |
|---|---|---|
| `code` | Yes | Authorization code from the provider |
| `state` | Yes | State from the provider; must match the `plexichat_oauth_state` cookie |
| `redirect_uri` | Yes | Same URI used at initiation (re-checked against the allow-list) |
| `code_verifier` | Yes when PKCE is enabled | Browser-held verifier; the server verifies it with `verify_pkce` (`src/api/routes/auth/oauth.py:413`) |

Response `200 OK` returns a standard `LoginResponse`. Error responses use `{"error":{"code":...,"message":"..."}}` with `400` for allow-list or PKCE failures, `404` for unknown providers, and `401` for token exchange failures.

### Use the session token

Include the token in every authenticated request:

```http
Authorization: Bearer session_token_here
```

For WebSocket gateway authentication, mint a single-use ticket first:

```http
POST /api/v1/auth/ws-ticket
Authorization: Bearer session_token_here
```

Response:

```json
{
  "ticket": "wst.example_ticket_value",
  "expires_in": 60
}
```

Send the ticket as the gateway `IDENTIFY` token. It is consumed on first use.

## Build an API client

### Create a basic client

```javascript
class PlexiAPI {
  constructor(baseUrl, token) {
    this.baseUrl = baseUrl;
    this.token = token;
  }

  async request(method, endpoint, data = null) {
    const url = `${this.baseUrl}${endpoint}`;
    const headers = {
      'Content-Type': 'application/json',
      'Authorization': `Bearer ${this.token}`
    };

    const options = { method, headers };
    if (data) {
      options.body = JSON.stringify(data);
    }

    const response = await fetch(url, options);

    if (!response.ok) {
      const body = await response.json().catch(() => ({}));
      // Errors use {"error":{"code":...,"message":"..."}} (src/api/schemas/common.py:58)
      const message = body.error?.message || `API error: ${response.status}`;
      const error = new Error(message);
      error.status = response.status;
      error.code = body.error?.code;
      throw error;
    }

    return response.json();
  }

  async getUser() {
    return this.request('GET', '/users/@me');
  }

  async getServers() {
    return this.request('GET', '/servers');
  }

  async getMessages(channelId, limit = 50) {
    return this.request('GET', `/channels/${channelId}/messages?limit=${limit}`);
  }

  async sendMessage(channelId, content) {
    return this.request('POST', `/channels/${channelId}/messages`, { content });
  }
}
```

### Handle errors

All errors use the standard envelope (`src/api/schemas/common.py:58`):

```json
{
  "error": {
    "code": 401,
    "message": "Invalid or expired token"
  }
}
```

| Status | Action |
|---|---|
| `400` | Fix the request (validation, `redirect_uri` allow-list, or PKCE format). |
| `401` | Prompt the user to re-authenticate. The token is invalid or expired. |
| `403` | Show a permission error. |
| `404` | Show a not-found state. For presence, `GET /users/{id}/presence` returns `404` when you are not self, a friend, or a shared server member; it does not return `offline`. |
| `429` | Retry after the delay in `Retry-After`. |
| `500` | Show a generic error and log the details. |

Handle `401` by redirecting to login. Handle `429` with the retry delay.

## Integrate with the WebSocket gateway

The gateway lives at `/gateway` (`src/api/websocket/gateway.py:261`). In local development, the Vite dev server proxies both `/api` and `/gateway` to the API server.

### Connect and identify

```javascript
class PlexiGateway {
  constructor(token, intents) {
    this.token = token;
    this.intents = intents;
    this.ws = null;
    this.sequence = 0;
    this.sessionId = null;
    this.heartbeatInterval = null;
  }

  connect() {
    // Use ws://localhost:8000/gateway in development, wss://your-host/gateway in production
    this.ws = new WebSocket('ws://localhost:8000/gateway');

    this.ws.onopen = () => {
      console.log('Gateway connected');
    };

    this.ws.onmessage = (event) => {
      this.handleMessage(JSON.parse(event.data));
    };

    this.ws.onclose = (event) => {
      console.log('Gateway disconnected:', event.code);
      this.handleReconnect();
    };
  }

  handleMessage(payload) {
    if (payload.s) this.sequence = payload.s;

    switch (payload.op) {
      case 10: // Hello
        this.identify();
        this.startHeartbeat(payload.d.heartbeat_interval);
        break;
      case 0: // Dispatch
        this.handleEvent(payload.t, payload.d);
        break;
      case 11: // Heartbeat ACK
        this.lastHeartbeatAck = Date.now();
        break;
    }
  }

  identify() {
    this.ws.send(JSON.stringify({
      op: 2,
      d: {
        token: this.token,
        properties: {
          os: 'windows',
          browser: 'custom-client',
          device: 'desktop'
        },
        intents: this.intents
      }
    }));
  }

  startHeartbeat(interval) {
    this.heartbeatInterval = setInterval(() => {
      this.ws.send(JSON.stringify({
        op: 1,
        d: this.sequence
      }));
    }, interval);
  }

  handleEvent(eventType, data) {
    switch (eventType) {
      case 'MESSAGE_CREATE':
        this.onMessageCreate(data);
        break;
      case 'PRESENCE_UPDATE':
        this.onPresenceUpdate(data);
        break;
      // Handle other events
    }
  }

  handleReconnect() {
    if (this.sessionId) {
      // Resume
      this.ws = new WebSocket('ws://localhost:8000/gateway');
      this.ws.onopen = () => {
        this.ws.send(JSON.stringify({
          op: 6,
          d: {
            token: this.token,
            session_id: this.sessionId,
            seq: this.sequence
          }
        }));
      };
    } else {
      // Fresh connect
      setTimeout(() => this.connect(), 5000);
    }
  }
}
```

### Handle gateway opcodes

Key opcodes from `src/api/websocket/opcodes.py:40`:

| Opcode | Name | Purpose |
|---|---|---|
| `0` | `DISPATCH` | Server dispatches an event |
| `1` | `HEARTBEAT` | Client heartbeat |
| `2` | `IDENTIFY` | Client authentication |
| `6` | `RESUME` | Resume a session |
| `10` | `HELLO` | Server hello with `heartbeat_interval` |
| `11` | `HEARTBEAT_ACK` | Server acknowledges heartbeat |
| `30` | `INTERACTION_CREATE` | Interaction dispatch |
| `50` | `RATCHET_UPDATE` | Channel ratchet |
| `60` | `ARTIFACT_SUBSCRIBE` | Subscribe to an artifact |
| `61` | `ARTIFACT_UNSUBSCRIBE` | Unsubscribe from an artifact |
| `62` | `ARTIFACT_OP` | Artifact operation |
| `63` | `ARTIFACT_SYNC` | Artifact sync |
| `64` | `SUM_SUBSCRIBE` | Subscribe to a PlexiSum workbook |
| `65` | `SUM_UNSUBSCRIBE` | Unsubscribe from a workbook |
| `66` | `SUM_OP` | Workbook operation |
| `67` | `SUM_SYNC` | Workbook sync |

### Cache with IndexedDB

Use IndexedDB for offline caching and instant rendering.

#### Create the schema

```javascript
const DB_NAME = 'PlexichatCache';
const DB_VERSION = 2;

async function initDB() {
  return new Promise((resolve, reject) => {
    const request = indexedDB.open(DB_NAME, DB_VERSION);

    request.onerror = () => reject(request.error);
    request.onsuccess = () => resolve(request.result);

    request.onupgradeneeded = (event) => {
      const db = event.target.result;

      if (!db.objectStoreNames.contains('messages')) {
        const msgStore = db.createObjectStore('messages', { keyPath: 'id' });
        msgStore.createIndex('channel_id', 'channel_id', { unique: false });
        msgStore.createIndex('created_at', 'created_at', { unique: false });
      }

      if (!db.objectStoreNames.contains('servers')) {
        db.createObjectStore('servers', { keyPath: 'id' });
      }

      if (!db.objectStoreNames.contains('channels')) {
        const chStore = db.createObjectStore('channels', { keyPath: 'id' });
        chStore.createIndex('server_id', 'server_id', { unique: false });
      }

      if (!db.objectStoreNames.contains('users')) {
        db.createObjectStore('users', { keyPath: 'id' });
      }
    };
  });
}
```

#### Cache messages

```javascript
async function cacheMessages(channelId, messages) {
  const tx = db.transaction('messages', 'readwrite');
  const store = tx.objectStore('messages');
  for (const msg of messages) {
    store.put({ ...msg, channel_id: channelId });
  }
}
```

#### Load cached messages

```javascript
async function getCachedMessages(channelId, limit = 50) {
  const tx = db.transaction('messages', 'readonly');
  const store = tx.objectStore('messages');
  const index = store.index('channel_id');
  const request = index.getAll(channelId);

  return new Promise((resolve) => {
    request.onsuccess = () => {
      const messages = request.result || [];
      messages.sort((a, b) => a.created_at - b.created_at);
      resolve(messages.slice(-limit));
    };
  });
}
```

### Invalidate the cache

- Clear channel messages when new messages arrive through the gateway.
- Refresh the server list on `GUILD_CREATE` and `GUILD_DELETE` dispatches.
- Update user data on `USER_UPDATE` dispatches.
- Version the cache to handle schema changes.

## Decrypt messages

Plexichat encrypts message content on the server. The client decrypts it with a key derived from the user ID and session token.

### Initialize crypto

```javascript
class PlexiCrypto {
  constructor(userId, token) {
    this.userId = userId;
    this.token = token;
    this.key = null;
  }

  async init() {
    const keyMaterial = await this.importKey(this.userId + this.token);
    this.key = await this.deriveKey(keyMaterial);
  }

  async importKey(password) {
    const enc = new TextEncoder();
    return window.crypto.subtle.importKey(
      'raw',
      enc.encode(password),
      'PBKDF2',
      false,
      ['deriveKey']
    );
  }

  async deriveKey(keyMaterial) {
    const salt = new TextEncoder().encode('plexichat-salt');
    return window.crypto.subtle.deriveKey(
      {
        name: 'PBKDF2',
        salt: salt,
        iterations: 100000,
        hash: 'SHA-256'
      },
      keyMaterial,
      { name: 'AES-GCM', length: 256 },
      false,
      ['encrypt', 'decrypt']
    );
  }

  async decrypt(encryptedContent) {
    if (!this.key) return encryptedContent;
    try {
      const data = JSON.parse(encryptedContent);
      const iv = this.base64ToArrayBuffer(data.iv);
      const ciphertext = this.base64ToArrayBuffer(data.ciphertext);
      const decrypted = await window.crypto.subtle.decrypt(
        { name: 'AES-GCM', iv: iv },
        this.key,
        ciphertext
      );
      const dec = new TextDecoder();
      return dec.decode(decrypted);
    } catch (e) {
      console.error('Decryption failed:', e);
      return encryptedContent;
    }
  }

  base64ToArrayBuffer(base64) {
    const binaryString = atob(base64);
    const bytes = new Uint8Array(binaryString.length);
    for (let i = 0; i < binaryString.length; i++) {
      bytes[i] = binaryString.charCodeAt(i);
    }
    return bytes.buffer;
  }
}
```

### Decrypt a message


## Use data types

### Snowflake IDs

Plexichat uses snowflake IDs for all entities. These 64-bit integers encode timestamps (`src/api/schemas/common.py:12`).

```javascript
function extractTimestamp(snowflake) {
  return (snowflake / 4194304) + 1420070400000;
}

const timestamp = extractTimestamp(messageId);
const date = new Date(timestamp);
```

Snowflake IDs serialize as strings in JSON.

### Timestamps

All timestamps are Unix timestamps in milliseconds.

```javascript
const date = new Date(message.created_at);
```

## Respect rate limits

API rate limits come from `src/config_defaults.py:273`:

| Scope | Limit | Window | Burst |
|---|---|---|---|
| Global | 25,000 | 60 seconds | 5,000 |
| User | 10,000 | 60 seconds | 2,500 |
| IP | 5,000 | 60 seconds | 1,500 |
| Hourly (user) | 300,000 | 3,600 seconds | — |
| Daily (user) | 5,000,000 | 86,400 seconds | — |

When you receive `429`, the body is:

```json
{
  "error": {
    "code": 429,
    "message": "Too many requests"
  }
}
```

Read `Retry-After` and retry after that delay. Use exponential backoff:

```javascript
async function requestWithRetry(fn, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (error.status === 429) {
        const retryAfter = error.retry_after || 5;
        await new Promise((resolve) => setTimeout(resolve, retryAfter * 1000));
      } else {
        throw error;
      }
    }
  }
}
```

## Complete example

```javascript
class PlexiClient {
  constructor(baseUrl) {
    this.api = new PlexiAPI(baseUrl);
    this.gateway = null;
    this.state = AppState;
    this.crypto = null;
  }

  async login(username, password) {
    const response = await this.api.request('POST', '/auth/login', {
      username,
      password
    });

    if (response.status === 'two_factor_required') {
      throw new Error('2FA required — complete the challenge via POST /auth/2fa');
    }

    this.api.token = response.token;
    this.state.currentUser = response.user;

    this.crypto = new PlexiCrypto(response.user.id, response.token);
    await this.crypto.init();

    this.gateway = new PlexiGateway(response.token, 3178237);
    this.gateway.connect();

    return response;
  }

  async loadServers() {
    const servers = await this.api.getServers();
    this.state.servers = servers;
    return servers;
  }

  async loadMessages(channelId) {
    const cached = await getCachedMessages(channelId);
    if (cached.length > 0) {
      this.state.messages[channelId] = cached;
    }

    const messages = await this.api.getMessages(channelId);
    this.state.messages[channelId] = messages;
    await cacheMessages(channelId, messages);

    return messages;
  }

  async sendMessage(channelId, content) {
    const message = await this.api.sendMessage(channelId, content);
    if (!this.state.messages[channelId]) {
      this.state.messages[channelId] = [];
    }
    this.state.messages[channelId].push(message);
    return message;
  }
}
```
